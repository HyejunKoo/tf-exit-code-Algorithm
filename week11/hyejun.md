# 오답노트

## 문제 1

- 문제명: 멀리 뛰기
- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12914
- 알고리즘 / 자료구조: DP

### 접근 및 시행착오

처음에는 경우의 수를 직접 구하려고 했다. n이 커질수록 경우의 수를 하나씩 세기 어려워져서 이전 결과를 이용하는 방식으로 바꿨다.

### 최종 풀이

n번째 칸에 오는 경우는 n-1번째 칸에서 1칸 뛰는 경우와 n-2번째 칸에서 2칸 뛰는 경우의 합이다.
따라서 `dp[n] = dp[n-1] + dp[n-2]`로 계산했다.

### 복잡도

- 시간복잡도: O(n)
- 공간복잡도: O(n)

### 핵심 포인트

이전 값으로 다음 값을 구할 수 있는 경우 DP를 생각해보기.

## 문제 2

- 문제명: 점프와 순간 이동
- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12980
- 알고리즘 / 자료구조: 그리디

### 접근 및 시행착오

처음에는 0부터 N까지 이동하는 방법을 생각했다. 반대로 N에서 0으로 줄여나가는 방식이 더 간단했다.

### 최종 풀이

N이 짝수면 2로 나누고, 홀수면 1을 빼면서 건전지 사용량을 1 증가시켰다.
N이 0이 될 때까지 반복했다.

### 복잡도

- 시간복잡도: O(log N)
- 공간복잡도: O(1)

### 핵심 포인트

정방향으로 풀기 복잡하면 반대로 줄여가는 방법도 생각해보기.

## 문제 3

- 문제명: N개의 최소공배수
- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12953
- 알고리즘 / 자료구조: 최대공약수, 최소공배수

### 접근 및 시행착오

여러 수의 최소공배수를 구하는 방법이 바로 떠오르지 않았다. 두 수씩 최소공배수를 구해서 누적하면 된다는 점을 이용했다.

### 최종 풀이

유클리드 호제법으로 최대공약수를 구하고 `a * b // gcd(a, b)`로 최소공배수를 계산했다.
계산한 최소공배수와 다음 숫자를 다시 계산하는 방식으로 반복했다.

### 복잡도

- 시간복잡도: O(n log M)
- 공간복잡도: O(1)

### 핵심 포인트

여러 수의 최소공배수는 두 수씩 순서대로 계산하면 된다.
