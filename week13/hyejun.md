# 오답노트

## 문제 1

- **문제명:** 할인 행사
- **문제 링크:** https://school.programmers.co.kr/learn/courses/30/lessons/131127
- **알고리즘 / 자료구조:** 슬라이딩 윈도우, 딕셔너리

### 접근 및 시행착오

원하는 물품이 모두 포함되는지만 확인하면 되는 줄 알았는데, 각 물품의 개수까지 맞아야 했다.
할인 기간이 10일로 고정돼 있으므로 10일씩 구간을 옮기며 개수를 비교하면 된다.

### 최종 풀이

1. 원하는 물품과 수량을 딕셔너리에 저장한다.
2. 할인 목록에서 연속된 10일의 물품 수량을 센다.
3. 원하는 수량과 모두 일치하면 정답을 1 증가시킨다.
4. 시작일을 하루씩 옮기며 반복한다.

### 복잡도

- 시간복잡도: O(n)
- 공간복잡도: O(1)

### 핵심 포인트

연속된 고정 길이 구간을 확인할 때는 슬라이딩 윈도우를 생각한다.

## 문제 2

- **문제명:** 괄호 회전하기
- **문제 링크:** https://school.programmers.co.kr/learn/courses/30/lessons/76502
- **알고리즘 / 자료구조:** 스택, 문자열 회전

### 접근 및 시행착오

여는 괄호와 닫는 괄호의 개수만 같아서는 올바른 문자열인지 판단할 수 없다.
닫는 괄호가 나올 때 가장 최근의 여는 괄호와 짝이 맞는지 확인해야 한다.

### 최종 풀이

1. 문자열을 한 칸씩 왼쪽으로 회전한다.
2. 각 문자열을 순회하며 여는 괄호는 스택에 넣는다.
3. 닫는 괄호가 나오면 스택 맨 위와 짝이 맞는지 확인한다.
4. 끝까지 검사한 뒤 스택이 비어 있으면 정답을 1 증가시킨다.

### 복잡도

- 시간복잡도: O(n²)
- 공간복잡도: O(n)

### 핵심 포인트

괄호의 짝과 순서를 함께 검사할 때는 스택을 사용한다.

## 문제 3

- **문제명:** n² 배열 자르기
- **문제 링크:** https://school.programmers.co.kr/learn/courses/30/lessons/87390
- **알고리즘 / 자료구조:** 인덱스 계산

### 접근 및 시행착오

처음에는 2차원 배열을 만든 뒤 잘라내는 방법을 생각했다.
하지만 n이 크면 배열 전체를 만들 수 없다. 각 위치의 값을 인덱스만으로 구하는 규칙이 필요했다.

### 최종 풀이

1. `left`부터 `right`까지 인덱스를 순회한다.
2. 각 인덱스의 행과 열을 `i // n`, `i % n`으로 구한다.
3. 해당 위치의 값인 `max(i // n, i % n) + 1`을 결과에 넣는다.
4. 결과 배열을 반환한다.

### 복잡도

- 시간복잡도: O(right - left + 1)
- 공간복잡도: O(right - left + 1)

### 핵심 포인트

배열 전체가 필요하지 않다면 원하는 인덱스의 값만 계산할 수 있는지 먼저 확인한다.
