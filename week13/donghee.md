# 오답노트

## 문제 1

- **문제명:** 둘만의 암호
- **문제 링크:** https://school.programmers.co.kr/learn/courses/30/lessons/155652
- **알고리즘 / 자료구조:** 구현(시뮬레이션) / 문자열

### 접근 및 시행착오

처음에는 문자열을 리스트 형태로 변환한 뒤 문자를 하나씩 비교해야 하나 생각했다. 하지만 `charAt()`을 활용하면 문자열에서 문자를 하나씩 꺼낼 수 있어 별도의 리스트 변환 없이 해결할 수 있었다.

풀이 과정에서 `indexOf()` 메서드를 새롭게 알게 되었고, 이를 활용해 특정 문자가 `skip` 문자열에 포함되어 있는지 확인할 수 있었다.

### 최종 풀이

1. `for`문과 `s.charAt(i)`를 활용해 문자열 `s`의 문자를 하나씩 순회한다.
2. 각 문자에 대해 `while`문을 실행하여 알파벳을 한 칸씩 뒤로 이동시킨다. (`a → b → c`)
3. 이동한 문자가 `skip`에 포함되어 있다면 `continue`로 건너뛰고 카운팅하지 않는다.
4. `skip`에 포함되지 않은 문자만 카운팅하여 `index`번 이동할 때까지 반복한다.
5. 최종 변환된 문자를 `StringBuilder`의 `append()`로 추가하고, 완성된 문자열을 반환한다.

### 복잡도

- **시간복잡도:** O(N × K × M)
  - N: `s`의 길이
  - K: `index`
  - M: `skip`의 길이
- **공간복잡도:** O(N)
  - 결과 문자열을 저장하는 `StringBuilder`에 O(N)의 공간이 필요하다.

### 핵심 포인트
- `indexOf(c)`는 문자가 존재하지 않으면 `-1`을 반환한다.
- `char`에 산술 연산을 수행하면 결과가 `int`가 되므로 형변환에 주의해야 한다.
- 알파벳은 순환하므로 `'z'` 다음 문자는 `'a'`가 되도록 처리해야 한다.

## 문제 2

* **문제명:** 같은 숫자는 싫어
* **문제 링크:** https://school.programmers.co.kr/learn/courses/30/lessons/12906
* **알고리즘 / 자료구조:** 스택/큐

### 접근 및 시행착오

처음에는 문제를 잘못 읽고 중복된 숫자를 모두 제거하면 되는 줄 알고 HashSet을 사용했다. 하지만 연속으로 나타나는 숫자만 제거해야 하며, 뒤에서 동일한 숫자가 다시 나오는 것은 허용되는 문제였다.

HashSet은 중복된 값을 모두 제거하고 원소의 순서도 보장하지 않기 때문에 적합하지 않았다.
따라서 ArrayList를 사용하고, 현재 원소와 이전 원소를 비교하는 방식으로 변경했다.


### 최종 풀이
1. ArrayList<Integer>를 생성하고 첫 번째 원소를 추가한다.
2. 배열의 두 번째 원소부터 순회하면서 현재 원소와 이전 원소를 비교한다.
3. 두 원소가 다를 경우에만 ArrayList에 추가한다.
4. stream().mapToInt(i -> i).toArray()를 사용해 ArrayList<Integer>를 int[]로 변환하여 반환한다.

### 복잡도

- **시간복잡도:**  O(N)
- **공간복잡도:**  O(N)

### 핵심 포인트

- HashSet은 모든 중복을 제거하므로 연속된 중복만 제거하는 문제에는 적합하지 않다.
- ArrayList<Integer>를 int[]로 변환할 때 stream().mapToInt(i -> i).toArray()를 사용할 수 있다.
