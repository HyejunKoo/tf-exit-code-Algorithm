# 오답노트

## 문제 1

- **문제명:** 연속 부분 수열 합의 개수
- **문제 링크:** https://school.programmers.co.kr/learn/courses/30/lessons/131701
- **알고리즘 / 자료구조:** 완전탐색, Set

### 접근 및 시행착오

부분 수열의 길이를 1부터 전체 길이까지 늘리며 합을 구하는 방식은 떠올렸다.  
원형 수열에서 배열의 끝과 처음이 이어지는 경우를 어떻게 처리할지 막혔다.  
원본 배열을 두 번 이어 붙이면 일반 배열처럼 연속 구간을 확인할 수 있다는 점을 알게 됐다.  
중복된 합은 별도로 개수를 세기보다 Set에 저장하면 자동으로 제거할 수 있다.

### 최종 풀이

1. 원본 배열을 두 번 이어 붙인다.
2. 부분 수열의 길이를 1부터 n까지 확인한다.
3. 각 길이마다 시작점을 0부터 n-1까지 이동한다.
4. 해당 구간의 합을 구해 Set에 저장한다.
5. Set에 저장된 값의 개수를 반환한다.

### 복잡도

- 시간복잡도: O(n³)
- 공간복잡도: O(n²)

### 핵심 포인트

원형 배열은 배열을 두 번 이어 붙이는 방식으로 처리할 수 있다.  
중복 제거가 필요하면 Set을 먼저 떠올린다.

## 문제 2

- **문제명:** 예상 대진표
- **문제 링크:** https://school.programmers.co.kr/learn/courses/30/lessons/12985
- **알고리즘 / 자료구조:** 반복문, 정수 나눗셈

### 접근 및 시행착오

라운드가 진행될 때 참가자 번호가 새로 배정된다는 점까지는 이해했지만, 번호가 바뀌는 규칙을 바로 식으로 만들지 못했다.  
1번과 2번은 1번, 3번과 4번은 2번이 되므로 다음 번호는 `(현재 번호 + 1) // 2`로 계산할 수 있다.

### 최종 풀이

1. A와 B의 번호가 같아질 때까지 반복한다.
2. 매 라운드마다 A와 B를 `(번호 + 1) // 2`로 갱신한다.
3. 한 번 갱신할 때마다 라운드 수를 1 증가시킨다.
4. 두 번호가 같아진 시점의 라운드 수를 반환한다.

### 복잡도

- 시간복잡도: O(log n)
- 공간복잡도: O(1)

### 핵심 포인트

토너먼트에서 다음 라운드 번호는 `(현재 번호 + 1) // 2`로 계산할 수 있다.  
두 참가자의 번호가 같아지는 순간이 서로 만나는 라운드다.

## 문제 3

- **문제명:** 영어 끝말잇기
- **문제 링크:** https://school.programmers.co.kr/learn/courses/30/lessons/12981
- **알고리즘 / 자료구조:** Set, 문자열, 인덱스 계산

### 접근 및 시행착오

이전에 나온 단어인지 확인하고 앞 단어의 마지막 글자와 현재 단어의 첫 글자를 비교해야 한다는 조건은 찾았다.  
탈락한 사람이 몇 번 사람인지, 몇 번째 차례인지 인덱스로 계산하는 부분이 바로 떠오르지 않았다.

### 최종 풀이

1. 지금까지 나온 단어를 저장할 Set을 만든다.
2. words를 앞에서부터 하나씩 확인한다.
3. 이미 나온 단어이거나 끝말잇기 규칙을 어기면 바로 탈락 처리한다.
4. 사람 번호는 `i % n + 1`로 계산한다.
5. 해당 사람의 차례는 `i // n + 1`로 계산한다.
6. 끝까지 탈락자가 없으면 `[0, 0]`을 반환한다.

### 복잡도

- 시간복잡도: O(m)
- 공간복잡도: O(m)

### 핵심 포인트

중복 확인은 Set을 사용하면 빠르게 처리할 수 있다.  
순서가 반복되는 문제에서는 `%`로 사람 번호, `//`로 몇 번째 차례인지 계산할 수 있다.
